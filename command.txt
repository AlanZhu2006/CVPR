# Mono2Sim-GS command index

This file is no longer the scratchpad for every historical branch. It is a
short index for the final-report version of the project.

## Main path: backend GPU video to Gaussian

Use:

```bash
bash scripts/runbooks/gpu_video_to_gaussian.sh
```

Read:

```text
docs/RUNBOOK_GPU_VIDEO_TO_GAUSSIAN.md
```

This path corresponds to the final report's main LG-GS / Route B experiment:

```text
RGB video frames
  -> LingBot pose/depth/confidence/point cloud
  -> GenWildSplat sparse context scene
  -> LingBot-guided Gaussian means
  -> display-scaled Gaussian PLY
  -> WebUI chunks
```

## Secondary path: live edge capture

Use:

```bash
bash scripts/runbooks/live_edge_capture.sh
```

Read:

```text
docs/RUNBOOK_LIVE_EDGE_CAPTURE.md
```

This path corresponds to the HikRobot / cuVSLAM / LingBot live demo:

```text
HikRobot RGB
  -> cuVSLAM low-latency pose
  -> asynchronous LingBot dense geometry
  -> RGB / point cloud / trajectory WebUI
```
