# Final Report LaTeX Package

This folder contains the expanded LaTeX final report generated from the provided course template.

Files:

- `main.tex`: report source
- `references.bib`: bibliography

Compile on Overleaf or a local TeX installation with:

```bash
pdflatex main
bibtex main
pdflatex main
pdflatex main
```

Before submission, replace the author placeholder in `main.tex`:

```tex
\href{mailto:your.email@nyu.edu}{Student Name(s)}
```

The report intentionally ignores the 5-8 page limit for now and is written as a detailed project draft.
